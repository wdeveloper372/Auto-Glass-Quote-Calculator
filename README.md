# Auto Glass Quote Calculator

A web app that helps employees calculate customer quotes quickly. I built it for my family's auto glass shop to replace manual calculations.

**Live demo:** https://deleon-calculator.tiiny.site/



## Features
* Calculates service and tax estimates in real time
* Responsive layout that works on desktop and phone
* Built for fast data entry

## Tech Stack
HTML, CSS, JavaScript

## Run it locally
Download the files and open `index.html` in a browser. No install is needed.
